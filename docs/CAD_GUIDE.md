# 模型使用指南

## 环境与入口

本次使用 SolidWorks 2020 SP1（API 修订号 28.1.0）读取检查。入口是根目录的 [`装配体1.SLDASM`](../装配体1.SLDASM)，配置名为“默认”。其他版本的读取和编辑兼容性未逐一测试。

所有 34 个零件文件均和装配体放在根目录。初始缺失的 6 个标准件依赖已按原文件名补齐，因此下载时请保留英文文件名、中文文件名和所有文件扩展名。

## 打开步骤

1. 完整克隆仓库，或下载并解压整个项目。
2. 使用 SolidWorks 打开根目录的装配体；首次查看可使用只读模式。
3. 若软件仍尝试访问原计算机的路径，在查找文件对话框中选择当前仓库根目录下的同名文件。原生 CAD 中可能保留历史引用路径。
4. 确认默认配置，解析轻化组件，并执行重建。打开时的提示和本次核查情况见 [VALIDATION.md](VALIDATION.md)。
5. 需要修改模型时，先创建工作副本。后续若需改名或移动文件，应在 SolidWorks 内管理引用，并重新检查装配依赖。

## 推荐查看顺序

先查看整机等轴测视图和组件树，再单独打开泵体、曲轴、拨叉、活塞等核心零件。结合[图纸页码索引](REFERENCES.md)检查尺寸与零件对应关系，再查看各端盖、阀板、气路接头和垫片。

原生模型可以用于检查现有几何和特征树。本次整理没有逐条审计草图约束、建模特征顺序或所有装配配合，因此文档中的阅读建议不是原始建模过程的复述。

## 导出与分享

需要在其他 CAD 软件中交换几何时，可在个人副本中导出 STEP 或 Parasolid。导出前先解析全部组件、重建并清除选择，确认导出范围覆盖整机。中性格式通常不保留原生参数特征树与装配配合，原生文件仍应作为编辑依据。

若要发布新截图，直接从本项目模型导出，并在说明中记录视角与配置。请勿把参考图纸或示意图标作模型实际渲染结果。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 找不到螺钉、销或垫圈 | 确认没有漏下载英文名称的 `.sldprt` 文件，并重新定位到根目录 |
| 找不到原磁盘路径 | 指向根目录同名文件；重新打包时用 Pack and Go 管理依赖 |
| 提示只读 | 本次检查主动使用只读打开；编辑时在工作副本中操作 |
| 提示需要重建 | 在个人副本中重建，检查特征或配合提示，再决定是否保存 |
| 旧版本不能读取 | 使用已核查版本读取，或由可打开文件的软件导出中性格式 |
| 网页只显示二进制文件 | 查看 README 内的 PNG 预览，或下载完整原生模型 |

## 修改后的检查

修改 CAD 后应重新检查依赖、组件配置和配合，必要时做干涉检查；更新截图、实例清单和文件哈希，并记录所用的软件版本。Python 文件检查只负责归档完整性，不会重建 CAD 或判断模型是否可制造。
